The grammar of graphics

Every ggplot is built from the same parts, added layer by layer with +:

  • data: a tibble, in long format
  • aesthetics (aes()): which column maps to x, y, colour, size, …
  • geoms: how the data is drawn (points, lines, bars, …)
  • scales, facets, themes and labels for everything else
yearly |>
  ggplot(aes(x = year, y = temp_mean))

The canvas and axes exist, but nothing is drawn until a geom is added.

Standard plot types

Scatter plot

yearly |>
  ggplot(aes(x = year, y = temp_mean)) +
  geom_point()

Line plot, and lines with points

Geoms stack: each + adds a layer on top of the previous one.

yearly |>
  ggplot(aes(x = year, y = temp_mean)) +
  geom_line(color = "grey60") +
  geom_point()

A smoother shows the trend; method = "loess" is a local average, method = "lm" a straight line.

yearly |>
  ggplot(aes(x = year, y = temp_mean)) +
  geom_line(color = "grey60") +
  geom_point() +
  geom_smooth(method = "loess", formula = y ~ x)

Bar plot

geom_col() draws bars of a given height; geom_bar() counts rows itself.

yearly |>
  filter(year >= 2000) |>
  ggplot(aes(x = year, y = hot_days)) +
  geom_col()

Histogram and density

The distribution of one variable: all daily maximum temperatures.

weather |>
  ggplot(aes(x = temp_max)) +
  geom_histogram(binwidth = 1)
weather |>
  ggplot(aes(x = temp_max)) +
  geom_density(fill = "grey80")

Boxplot

Distributions side by side, one per group.

weather |>
  ggplot(aes(x = factor(month), y = temp_max)) +
  geom_boxplot()

Groups and colours

Mapping a column to color (or fill) splits the data into groups and adds a legend.

seasonal <- weather |>
  mutate(year = year(date)) |>
  filter(year >= 1900, year <= 2025) |>
  group_by(year, season) |>
  summarize(temp_mean = mean(temp_mean, na.rm = TRUE)) |>
  ungroup()
`summarise()` has regrouped the output.
ℹ Summaries were computed grouped by year and season.
ℹ Output is grouped by year.
ℹ Use `summarise(.groups = "drop_last")` to silence this message.
ℹ Use `summarise(.by = c(year, season))` for per-operation grouping (`?dplyr::dplyr_by`) instead.

seasonal |>
  ggplot(aes(x = year, y = temp_mean, color = season)) +
  geom_line()

fct_relevel() puts the seasons in a meaningful order instead of the alphabetical default.

season_order <- c("Winter", "Spring", "Summer", "Autumn")

seasonal <- seasonal |>
  mutate(season = fct_relevel(season, season_order))

Facets

One small panel per group, same axes: often easier to read than four colours in one panel.

seasonal |>
  ggplot(aes(x = year, y = temp_mean)) +
  geom_line(color = "grey60") +
  geom_smooth(method = "loess", formula = y ~ x) +
  facet_wrap(~ season)

scales = "free_y" gives each panel its own y axis, which shows the trend within each season better.

seasonal |>
  ggplot(aes(x = year, y = temp_mean)) +
  geom_line(color = "grey60") +
  geom_smooth(method = "loess", formula = y ~ x) +
  facet_wrap(~ season, scales = "free_y")

Scales and labels

Manual colours

A named vector maps each group to a colour.

season_colors <- c(
  Winter = "#3B6FB6",
  Spring = "#6AA84F",
  Summer = "#E69138",
  Autumn = "#A64D79"
)

seasonal |>
  ggplot(aes(x = year, y = temp_mean, color = season)) +
  geom_line(alpha = 0.4) +
  geom_smooth(method = "loess", formula = y ~ x, se = FALSE) +
  scale_color_manual(values = season_colors)

Continuous colour scales

A diverging colour scale for the deviation from the 1961–1990 mean.

reference_period <- 1961:1990

reference_temp <- yearly |>
  filter(year %in% reference_period) |>
  summarize(reference = mean(temp_mean)) |>
  pull(reference)

yearly <- yearly |>
  mutate(anomaly = temp_mean - reference_temp)
yearly |>
  ggplot(aes(x = year, y = anomaly, fill = anomaly)) +
  geom_col() +
  scale_fill_gradient2(low = "#2166AC", mid = "white", high = "#B2182B")

Axis labels with the scales package

labs() names everything; the scales package formats axis labels.

yearly |>
  ggplot(aes(x = year, y = anomaly, fill = anomaly)) +
  geom_col() +
  scale_fill_gradient2(low = "#2166AC", mid = "white", high = "#B2182B", guide = "none") +
  scale_y_continuous(labels = label_number(suffix = " °C", style_positive = "plus")) +
  scale_x_continuous(breaks = breaks_width(20)) +
  labs(
    title = "Karlsruhe is getting warmer",
    subtitle = "Annual mean temperature vs. 1961-1990 average",
    x = NULL,
    y = "Deviation",
    caption = "Data: Deutscher Wetterdienst"
  )

Themes

theme_*() functions change the whole look at once, theme() single elements.

anomaly_plot <- yearly |>
  ggplot(aes(x = year, y = anomaly, fill = anomaly)) +
  geom_col() +
  scale_fill_gradient2(low = "#2166AC", mid = "white", high = "#B2182B", guide = "none") +
  labs(
    title = "Karlsruhe is getting warmer",
    x = NULL,
    y = "Deviation (°C)"
  )

anomaly_plot + theme_minimal()

A custom theme is just a function returning a theme, so every plot of a project looks the same:

theme_report <- function(base_size = 12) {
  theme_minimal(base_size = base_size) +
    theme(
      plot.title = element_text(face = "bold"),
      plot.title.position = "plot",
      panel.grid.minor = element_blank(),
      legend.position = "bottom"
    )
}

anomaly_plot + theme_report()

theme_set(theme_report()) would make it the default for all following plots.

Showcase: warming stripes

Everything removed except the colour: one stripe per year (after Ed Hawkins’ “warming stripes”).

yearly |>
  ggplot(aes(x = year, y = 1, fill = anomaly)) +
  geom_tile() +
  scale_fill_gradient2(low = "#2166AC", mid = "white", high = "#B2182B", guide = "none") +
  theme_void()

Multiple plots with patchwork

patchwork combines finished plots with + (side by side) and / (stacked).

temp_plot <- yearly |>
  ggplot(aes(x = year, y = temp_mean)) +
  geom_line() +
  labs(
    title = "Mean temperature",
    x = NULL,
    y = "°C"
  )

hot_plot <- yearly |>
  ggplot(aes(x = year, y = hot_days)) +
  geom_col() +
  labs(
    title = "Days of 30 °C or more",
    x = NULL,
    y = "Days"
  )

precip_plot <- yearly |>
  ggplot(aes(x = year, y = precip)) +
  geom_line() +
  labs(
    title = "Precipitation",
    x = NULL,
    y = "mm"
  )

(temp_plot + hot_plot) / precip_plot +
  plot_annotation(tag_levels = "A") &
  theme_report()

& applies a theme to every sub-plot, + only to the last one.

Saving plots

ggsave() saves the last plot, or the one given in plot = .... Width and height are in inches by default; dpi only matters for raster formats (PNG), a PDF is vector graphics.

ggsave("c02/anomaly.png", plot = anomaly_plot, width = 7, height = 4, dpi = 300)
ggsave("c02/anomaly.pdf", plot = anomaly_plot, width = 7, height = 4)

Text sizes are absolute (pt): the same plot saved at a larger width has relatively smaller text. Pick the size you’ll print at (e.g. 16 cm for a page in a thesis, units = "cm") instead of scaling the image afterwards.

Interactive plots with plotly

ggplotly() turns (most) ggplots into interactive HTML: hover, zoom, toggle groups in the legend. Works in HTML output only, not in PDF.

seasonal_plot <- seasonal |>
  ggplot(aes(x = year, y = temp_mean, color = season)) +
  geom_line() +
  scale_color_manual(values = season_colors) +
  labs(
    x = NULL,
    y = "Mean temperature (°C)",
    color = NULL
  )

ggplotly(seasonal_plot)

Try it: hot days per decade

Your task: draw a bar chart of the average number of days of 30 °C or more per year, by decade (1900s to 2010s), with readable axis labels, a title, and the custom theme.

yearly |>
  mutate(decade = year %/% 10 * 10) |>
  filter(decade >= 1900, decade <= 2010) |>
  group_by(decade) |>
  summarize(hot_days = mean(hot_days)) |>
  ggplot(aes(x = decade, y = hot_days)) +
  geom_col(fill = "#B2182B") +
  scale_x_continuous(breaks = breaks_width(10), labels = label_number(big.mark = "", suffix = "s")) +
  labs(
    title = "Hot days are becoming common",
    x = NULL,
    y = "Days of 30 °C or more per year"
  ) +
  theme_report()

Try it: then vs. now

Your task: compare the distribution of daily maximum temperatures in summer (June to August) for 1961–1990 and 1996–2025, as two overlapping densities in one plot, and as two facets of a histogram combined with patchwork.

summer_periods <- weather |>
  mutate(year = year(date)) |>
  filter(season == "Summer") |>
  mutate(
    period = case_when(
      year %in% 1961:1990 ~ "1961-1990",
      year %in% 1996:2025 ~ "1996-2025"
    )
  ) |>
  filter(!is.na(period))

density_plot <- summer_periods |>
  ggplot(aes(x = temp_max, fill = period)) +
  geom_density(alpha = 0.5) +
  labs(
    x = "Daily maximum (°C)",
    y = NULL,
    fill = NULL
  )

histogram_plot <- summer_periods |>
  ggplot(aes(x = temp_max)) +
  geom_histogram(binwidth = 1) +
  facet_wrap(~ period, ncol = 1) +
  labs(
    x = "Daily maximum (°C)",
    y = "Days"
  )

density_plot + histogram_plot +
  plot_annotation(title = "Summer maxima: then vs. now") &
  theme_report()
